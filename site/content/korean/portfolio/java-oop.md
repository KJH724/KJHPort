## 1. 활용 기술 및 적용 사례

본 실습에서는 Java 객체지향 프로그래밍 수업에서 학습한 개념을 실제 코드에 적용하였습니다.

클래스, 객체, 생성자, 배열 및 인터페이스를 활용하여 음식과 운동의 칼로리를 계산하는 프로그램을 구현하였습니다.

## 3. 활동 목적

객체지향 프로그래밍의 주요 개념인 클래스와 상속, 인터페이스를 학습하고 이를 문제 해결 과정에 스스로 적용하고자 하였습니다. 이 과정을 통해 객체지향 프로그래밍 개념을 충분히 이해한 것이 맞는지 확인할 수 있기에 실습하게 되었습니다.


## 4. 본인 역할 및 기여 범위

이 활동은 개인 실습으로 진행되었습니다.

먼저 문제를 분석한 뒤 필요한 인터페이스를 만들고, 이를 상속한 자식 클래스를 설계하였습니다. 그 후 멤버변수, 생성자 및 메소드를 활용하여 프로그램을 구체적으로 구현하였습니다.


## 5. 수행 과정 및 선택 이유

### 5-1. 문제 분석

음식의 섭취 칼로리와 운동의 소모 칼로리를 계산하고, 두 값이 같아지도록 음식의 중량을 조절하는 프로그램의 요구사항을 분석하였습니다.

### 5-2. 클래스 및 인터페이스

음식과 운동을 각각 Food, Workout 클래스로 구분하고, 공통으로 사용하는 prtInfo()와 computeKcal() 메소드를 FunctionName 인터페이스에 정의하였습니다.

- FunctionName 인터페이스

음식, 운동 클래스에서 공통으로 사용할 메소드를 정의하였습니다.

### 5-3. 구현 방식 선택 이유

음식과 운동 모두 칼로리를 계산하고 정보를 출력하는 기능이 필요하므로, 공통 메소드를 정의할 수 있는 인터페이스를 사용하였습니다.

FunctionName 인터페이스에 computeKcal()와 prtInfo() 메소드를 정의하고, Food와 Workout 자식클래스에서 각각 구현하였습니다.

공통으로 필요한 기능을 편리하게 하나의 인터페이스로 관리할 수 있고, 상속을 통해 클래스마다 서로 다른 계산식 유지할 수 있으므로 이러한 방식을 선택하였습니다.
